## 配图使用约定

- 修改图时保留可编辑图源，并将正文使用的导出版本放在相应格式目录。
- 各种图源和导出版本不一定一一对应，按内容和文件名选择适合正文的版本。
- 图像清单中的 `assets/figures/…` 路径以项目根目录为基准；文稿中的实际图片链接以文稿所在目录为基准。
- `CAPANet/results/` 和 `CAPANet/output/` 中的运行输出由 Git 忽略，选定的论文效果图应整理到本目录。
