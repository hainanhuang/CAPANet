# CAPANet 论文图与效果图准备清单

本文若以 CAPANet 为核心投稿，除了定量表格之外，还需要准备一组能够解释“为什么有效”的图。图的目标不是重复表格结论，而是把三个创新点可视化出来：

1. `DPR` 证明模型确实按内容组织跨区域相似 token。
2. `PFSA` 证明模型确实筛掉冗余连接，并形成更干净的注意力路径。
3. `LMR` 证明模型确实按照低频结构、中频边界、高频纹理递进重建。

建议论文主文至少准备 `6-8` 张图，补充材料再放更多可视化与失败案例。

- 与 Routing Mode 和 DPR Internal Design 消融互相补证。

### Figure 8：动态焦点率与内容纯度关系图

目的：证明动态 `r` 是有内容依据的，不是人为调参。

建议形式：

| 图 | 横轴 | 纵轴 | 结论 |
| :--- | :--- | :--- | :--- |
| Scatter | cluster purity | dynamic keep ratio `r` | 纯组保留更多连接 |
| Scatter | x_scores variance | dynamic keep ratio `r` | 混杂组降低连接密度 |
| Bar | fixed r / dynamic r | Urban100/Manga109 PSNR | 动态 r 更优 |

推荐放置：主文分析图或补充材料。

和创新点的关系：

- 直接支撑 `PFSA` 的内容感知稀疏机制。
- 与 Dynamic Focus Ratio 消融配合，解释为什么 dynamic r 在平均保留比例不最高时仍然最好。

---

### Figure 9：注意力分布图

目的：证明 CAPANet 的注意力不是均匀扩散，也不是只看局部邻域，而是集中到与当前 query 语义或纹理相关的关键区域。

注意力分布图和稀疏 mask 图要区分：

| 图类型 | 展示内容 | 回答问题 |
| :--- | :--- | :--- |
| Attention distribution heatmap | 注意力权重在图像空间上的强弱分布 | 模型实际关注哪里 |
| Sparse mask / top-k connection map | 哪些 token 连接被保留或删除 | PFSA 怎样减少冗余连接 |
| Attention entropy / concentration curve | 注意力分布是否更集中 | 渐进聚焦是否成立 |

建议选择同一 query token，对比以下方法或模块：

| 对比项 | 预期现象 |
| :--- | :--- |
| Dense attention | 注意力更分散，容易覆盖无关纹理 |
| Fixed top-k attention | 有稀疏性，但不一定与内容纯度匹配 |
| PFSA | 注意力集中到相似纹理、重复结构或有效边界 |
| PFSA + DPR + LMR | 在跨区域相似结构和高频细节处形成更稳定关注 |

推荐样例：

| 数据集 | Query 位置 | 观察重点 |
| :--- | :--- | :--- |
| Urban100 | 建筑窗格、栏杆交叉点、斜线边缘 | 是否关注远距离重复窗格和同方向线条 |
| Manga109 | 人物轮廓、细线条、文字边缘、网点区域 | 是否避开无关背景并聚焦线稿纹理 |

建议图形组织：

```text
Input crop + query point
Dense attention heatmap
PFSA attention heatmap
CAPANet attention heatmap
HR / reconstruction crop
```

也可以补一个随 block 深度变化的序列：

```text
Block 1 attention -> Block 4 attention -> Block 8 attention
```

预期结论：

1. 早期 attention 仍较分散，深层逐步向关键结构收敛。
2. DPR 使远距离相似纹理进入可交互范围。
3. PFSA 让注意力权重从无关 token 中收缩到高价值连接。
4. LMR 的 LF/MF/HF 分支会呈现不同粒度的注意力分布。

这张图很适合放主文分析部分。若篇幅有限，至少在补充材料中提供。


观察点：

1. `w/o DPR`：重复结构错配或线条不连续。
2. `w/o PFSA`：边缘附近噪声或伪纹理更多。
3. `w/o LMR`：整体结构或中尺度边界不稳定。
4. `CAPANet`：结构连续、边界清晰、纹理更自然。

建议保留少量失败案例，增强论文可信度。

可能场景：

1. 极强随机纹理，DPR 难以形成稳定原型。
2. 非重复、非结构化细节，CAPANet 优势不明显。
3. 真实退化与 bicubic 退化差异大，模型可能过锐化。

失败案例不建议放主文大图，可以放补充材料或讨论部分。

## 5. 效果图制作规范

### 5.1 选择样例原则

优先选择能够体现 CAPANet 创新点的样例：

1. 远距离重复纹理明显，适合展示 DPR。
2. 边界附近有干扰纹理，适合展示 PFSA。
3. 同时包含大结构和细纹理，适合展示 LMR。

不建议只选 Set5 这种简单图像作为主视觉对比，因为难以体现 CAPANet 相比 CATANet/PFT 的机制优势。

### 5.2 局部放大框设计

每张效果图建议包含：

1. 原图位置框。
2. 放大区域。
3. 每个方法对应同一区域。
4. HR 作为最后一列或第一列。
5. 必要时增加 error map。

放大框应聚焦：

- 建筑直线是否断裂。
- 斜线方向是否一致。
- 漫画线稿是否粘连。
- 网点纹理是否变成噪声。
- 高频边缘是否过锐化。

### 5.3 对比方法选择

主文效果图建议至少包含：

| 方法 | 原因 |
| :--- | :--- |
| Bicubic | 基础退化参考 |
| CATANet | 与内容聚合机制最相关 |
| PFT-light | 与渐进聚焦注意力最相关 |
| SwinIR-light 或 SPIN | 代表轻量 Transformer / 混合方法 |
| CAPANet | 本文方法 |
| HR | 真实目标 |

如果版面有限，优先保留 `CATANet`、`PFT-light`、`CAPANet`、`HR`。

```python
def add_crop_box(img, box, color=(255, 0, 0), thickness=2):
    """在图像上画局部放大框，返回带框图像和放大区域。"""
    x, y, w, h = box

    cv2.rectangle(img_boxed, (x, y), (x + w, y + h), color, thickness)

def make_comparison(image_name, methods, box, save_path):

                                  interpolation=cv2.INTER_NEAREST)

        axes[1][col].axis('off')
```

### 8.3 DPR 路由质量可视化（Figure 7）

**目标**：将每个 token 按所属 prototype 染色，展示 DPR 按语义而非空间位置分组。

**Step 1：在 `capanet_arch.py` 的 `CAPABlock.forward` 中添加钩子，导出路由信息**

```python
# 在 CAPABlock.forward 中，dpr 调用之后临时插入：
sorted_x, idx_last, sorted_labels, x_scores, prototypes = self.dpr(normed_x)

# --- 可视化钩子（仅推理时启用）---
if getattr(self, '_vis_hook', False):
    self._vis_sorted_labels = sorted_labels.detach().cpu()  # (B, N)
    self._vis_x_scores = x_scores.detach().cpu()            # (B, N)
    self._vis_prototypes = prototypes.detach().cpu()         # (B, K, C)
    # 还原到原始空间顺序（unsort）
    unsort_idx = torch.argsort(idx_last.squeeze(-1), dim=1)
    self._vis_orig_labels = torch.gather(
        sorted_labels, 1, unsort_idx)                        # (B, N) 原始位置 → prototype id
```

**Step 2：新建 `scripts/visualize_dpr.py`**

```python
    img = np.array(Image.open(lr_path).convert('RGB')).astype(np.float32) / 255.0
    lq = torch.from_numpy(img).permute(2, 0, 1).unsqueeze(0)

    axes[0].axis('off')
    axes[1].imshow(color_map)
    axes[1].set_title(f'DPR Prototype Map (Block {block_idx})')
    axes[1].axis('off')
    # 叠加
    overlay = 0.5 * img + 0.5 * color_map
    axes[2].imshow(overlay.clip(0, 1))
    axes[2].set_title('Overlay')
    axes[2].axis('off')
    plt.tight_layout()
    plt.savefig(save_path, dpi=300, bbox_inches='tight')
    plt.close()
    print(f"DPR routing saved: {save_path}")
    target_block._vis_hook = False
```

```python
def visualize_lmr_branches(
    model, lr_path, block_idx=4,
    save_path='output/lmr_branches.png'
):
    lmr = model.blocks[block_idx][0].lmr
    lmr._vis_hook = True

    img = np.array(Image.open(lr_path).convert('RGB')).astype(np.float32) / 255.0
    H, W = img.shape[:2]
    lq = torch.from_numpy(img).permute(2, 0, 1).unsqueeze(0)

    with torch.no_grad():
        _ = model(lq)

    def to_energy_map(feat, H, W):
        """feat: (1, N, C) → 对 C 维取 L2 norm → (H, W) 热力图"""

        side = int(round(e.shape[0] ** 0.5))

        return e_map

    lf_map = to_energy_map(lmr._vis_lf_out, H, W)
    mf_map = to_energy_map(lmr._vis_mf_out, H, W)
    hf_map = to_energy_map(lmr._vis_hf_out, H, W)

    axes[0].set_title('LR Input')
```

```python
    if result.returncode != 0:
        print(f'[ERROR] {s} failed:\n{result.stderr}')
```
