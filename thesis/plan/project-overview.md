## 研究问题与方法

| 研究问题 | 方法模块 | 需要建立的证据 |
| --- | --- | --- |
| 跨区域相似纹理难以有效组织 | DPR：动态语义原型路由 | 路由方式、动态原型和 query refine 对照，路由可视化 |
| 无效注意力连接与计算资源分配不均 | PFSA：渐进聚焦稀疏注意力 | 稠密 / 稀疏对照、动态焦点率、注意力继承、实测效率 |
| 主体结构、边缘过渡与细节恢复缺少协同 | LMR：低到高多级协同重建 | 递进 / 并行 / 无跨级 / 反向路径对照，分支响应和定性结果 |

三者属于同一 CAPANet 框架。概念上依次承担信息组织、连接筛选和递进重建；实际代码由 LMR 的不同层级调用 PFSA，正文与结构图应说明这一关系。

## 当前必须澄清的差异

1. 两份 Baseline 笔记中的 CATANet 作者、年份和 arXiv 标识，与 DPR 文献笔记及代码 README 中的信息不一致，必须回原论文核对。
2. 核心消融 A（No TAB）、B（Dense CAPA + DPR）缺少当前独立结构开关。不能仅用已有的近似切换结果证明严格的 A/B 对照。
3. 实验记录把乘加统计列写成 FLOPs / MACs，需统一 MACs 与 FLOPs 的定义、倍率和统计范围。
4. PFSA 的连接掩码不自动代表实际执行了更少乘加运算，效率主张须由实现方式和测量支持。
5. LMR 的 LF / MF / HF 对应不同 token 粒度的特征分支；现有实现并未提供严格的频域分解，正文须限定“频率层级”的含义。

## 执行约定

- 主实验沿用 DIV2K 训练、Set5 / Set14 / BSD100 / Urban100 / Manga109 测试、×2 / ×3 / ×4 倍率。
- 消融与机制分析优先采用 ×4。匹配配置、初始化和训练预算后，复用已有完整模型证据，只补缺失项目。
- 每份正文按规范合规和内容质量两阶段检查，并记录作者反馈后推进。
- 参考论文的数据、本人实验结果和待验证记录分别标明来源；不生成模拟性能数值作为论文结论。
- 标准 SISR 实验保留，并按评委意见补充真实场景与实际部署测试；场景和设备待确定，部署性能主张必须有对应设备证据。
- 开题资料和代码保持原内容；规划文件随作者补充意见持续更新。
