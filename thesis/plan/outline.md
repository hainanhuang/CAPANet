# 毕业论文建议大纲

版本：v1，2026-11-21。依据开题报告和现有技术方案提出，正式写作前结合导师意见与学校要求确定。本轮未生成正文。

开题评委的八条意见已登记在 [计划清单](毕业论文计划清单.md) H01—H08。章节结构暂保留，待明确题目、核心贡献及轻量级 / 重建性能定位后调整；后续重点补充文献逻辑、实际部署、轻量化指标、性能—效率分析，并检查重复段落和图片信息量。

## 章节安排原则

按硕士工科论文组织六个正文章节。第 3、4 章从不同技术层面说明同一个 CAPANet，第 5 章统一验证，避免把相互依赖的模块写成两个已独立完成的方法。

篇幅暂按正文约 2.3万—3万字分配，仅用于估算工作量，不作为学校字数要求。摘要、参考文献和附录另计。

| 部分 | 建议篇幅 | 核心职责 |
| --- | --- | --- |
| 中英文摘要 | 各按学校要求 | 交代问题、方法、实测结果和结论，定稿阶段撰写 |
| 第 1 章 绪论 | 3,500—4,500 字 | 背景、问题、研究内容与贡献 |
| 第 2 章 相关研究与理论基础 | 4,000—5,000 字 | 研究谱系、机制比较和必要基础 |
| 第 3 章 内容自适应路由与渐进聚焦注意力方法 | 5,000—6,500 字 | CAPANet 总体框架、DPR 与 PFSA |
| 第 4 章 低到高多级协同重建与网络集成 | 3,500—5,000 字 | LMR、跨级注入、网络协同与实现 |
| 第 5 章 实验结果与分析 | 5,500—7,000 字 | 协议、主结果、消融、效率、机制和失效案例 |
| 第 6 章 总结 | 1,000—1,500 字 | 已验证结论、贡献与局限性 |
| 参考文献、致谢、附录 | 按学校要求 | 规范引用与可复现补充资料 |

- 1.4 本文研究内容与可验证贡献。
- 1.5 论文结构安排。

主要依据：[开题报告](../../proposal/开题报告.md)的选题依据、研究目标、关键问题和创新点。

## 支撑部分

- 中英文摘要在主实验与结论确定后撰写，数值与正文表格一致。
- 参考文献按学校要求统一作者、年份、出处和引用顺序。
- 附录可保存最终配置、实验索引、符号说明和补充图。
- 致谢与封面信息由作者核对。

## 建议写作顺序

锁定实验来源与方法定义 → 第 3 / 4 章 → 第 2 章 → 第 5 章 → 第 1 章 → 第 6 章 → 中英文摘要 → 全文检查。

文献整理、方法写作和缺失实验可并行；结果章节必须等待对应数据核验。
